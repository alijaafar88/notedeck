# C2: Deck List and Card Detail screens

Build two static screens with fake data, Material 3 theming and previews.

- [ ] A Deck List screen shows fake decks in a `LazyColumn` with keys
- [ ] A Card Detail screen shows one card's front and back
- [ ] Both screens use `MaterialTheme` tokens, with no hard-coded colours
- [ ] Each screen has light and dark previews with fake data

When you're done, run the app on an emulator and run `./gradlew test`, then answer the verify question in the KotlinDroid Daily app.
Stuck? Compare with the `c2-solution` tag, but finish by hand first. Afterwards, try the AI-pair follow-up from the app.
