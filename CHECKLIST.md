# K1: A deck on the console

Start NoteDeck as pure Kotlin, with no Android yet.

- [ ] `:core:model` defines `Card` and `Deck` as data classes
- [ ] `:core:model` has no Android dependency
- [ ] `./gradlew :cli:run` prints a hard-coded deck's name and its cards

When you're done, run `./gradlew test`, then answer the verify question in the KotlinDroid Daily app.
Stuck? Compare with the `k1-solution` tag, but finish by hand first.
